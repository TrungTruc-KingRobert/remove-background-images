# 🖼️ Background Remover Tool

Ứng dụng web hiện đại để xóa phông nền hình ảnh và thay thế bằng màu nền tùy chọn.

## ✨ Tính năng

- 🎯 **Xóa phông nền tự động** bằng AI
- 🎨 **Chọn màu nền mới** với color picker và preset colors
- 📱 **Giao diện responsive** với Tailwind CSS
- ⬇️ **Tải xuống riêng biệt** cho hình xóa nền và hình có nền mới
- 🔔 **Thông báo toast** thân thiện với người dùng
- 📂 **Drag & Drop** hoặc click để upload

## 🛠️ Công nghệ sử dụng

- **React 18** - Framework chính
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **@imgly/background-removal** - AI xóa phông nền
- **React-Toastify** - Thông báo
- **Canvas API** - Xử lý hình ảnh

## 📦 Cài đặt local

```bash
# Clone repository
git clone https://github.com/TrungTruc-KingRobert/remove-background-images.git

# Di chuyển vào thư mục
cd remove-background-images

# Cài đặt dependencies
npm install

# Chạy development server
npm run dev
```

## 🎯 Cách sử dụng

1. **Upload hình ảnh** - Kéo thả hoặc click để chọn file
2. **Chờ xử lý** - AI sẽ tự động xóa phông nền
3. **Chọn màu nền** - Sử dụng color picker hoặc preset colors
4. **Tải xuống** - Chọn loại hình ảnh muốn tải:
   - 🖼️ **Background Removed**: Hình có nền trong suốt
   - 🎨 **With New Background**: Hình với màu nền mới
